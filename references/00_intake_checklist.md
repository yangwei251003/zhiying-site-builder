# 阶段0 · 需要用户提供的信息与素材清单

在开始任何设计或开发之前，agent 必须确认以下信息齐全（缺的要主动问，不要假设）：

## 1. 品牌与视觉资产
- [ ] Logo 文件（矢量优先：svg/ai；没有的话用最高分辨率的 png）
- [ ] IP 形象/吉祥物 全套素材（不同姿态/表情，如果只有一张也先收着）
- [ ] 已有功能图标素材
- [ ] 品牌色 / VI 规范文档（如果有；没有的话从 Logo 和 IP 形象里提炼）
- [ ] 品牌名称的中英文写法、Slogan（如果已经想好）

## 2. 产品定位
- [ ] 网站的核心定位一句话描述（"职映是一个帮你……的平台"）
- [ ] 目标用户群体（学生求职/在职跳槽/海外求职/特定行业人群？）
- [ ] 与市面上同类产品（如 Teal、Rezi、各类 AI 简历工具）相比的差异化卖点
- [ ] 商业模式（免费？订阅付费？按次付费？部分功能免费+高级功能付费？）

## 3. 功能范围
- [ ] 网站需要呈现 resumecraft 的哪些能力（知识库构建、岗位匹配分析、简历生成、学习路径建议、面试建议……全部还是部分先上线）
- [ ] 是否需要用户账号体系（注册/登录、第三方登录如微信/Google）
- [ ] 是否需要多份知识库/多份简历版本管理
- [ ] 是否需要历史记录、版本对比
- [ ] 是否需要分享/导出功能（导出 PDF/Word、分享链接）
- [ ] 是否涉及支付（订阅/单次购买），有的话需要确认接入哪个支付渠道

## 4. 技术与运营约束
- [ ] 是否已有技术栈偏好（前端框架、后端语言、数据库），没有则由 agent 在阶段5 给出建议
- [ ] 部署目标（自建服务器/云厂商/Vercel 类平台），是否已有域名
- [ ] 预计上线时间/优先级排序（如果时间紧，先做 MVP 哪些功能）
- [ ] 是否需要多语言支持（中文为主，是否要英文版）
- [ ] 是否有合规/隐私方面的特殊要求（如需要隐私政策、用户协议页面）

## 5. 内容与文案
- [ ] 网站文案的语气调性（专业严谨 / 亲切活泼 / 年轻化），可以参考 IP 形象的性格做判断
- [ ] 是否已有核心文案素材（Slogan、功能介绍文字），没有的话 agent 在 PRD 阶段一并产出供确认

收集方式：不要一次性把这份清单原文甩给用户，拆成几轮对话自然地问，每轮问完做个小结确认。如果用户某一项暂时给不出来（比如还没想好商业模式），记录为"待定，先按免费版 MVP 设计，预留付费扩展空间"，不要卡在这里不推进。
