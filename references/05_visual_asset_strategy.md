# 阶段4 · 视觉素材生成策略

## 1. 先盘点缺口，再决定生成什么

把阶段3 每个页面/模块列出的"需要的视觉素材"汇总成一张清单，标注：

| 位置 | 素材类型 | 已有可用 | 需要生图 | 风格要求 |
|---|---|---|---|---|
| 首页Hero | IP形象插画 | ✅（已有，需要适配构图裁切） | | 延续已有IP风格 |
| 知识库构建页 | 步骤图标 x N | 部分已有 | 缺的部分需要生图 | 与已有图标同一线条粗细/风格 |
| ... | | | | |

已有素材优先复用（裁切、配色微调以适配场景），缺口部分才生图，不要为了"统一感"重新生成已经有的东西。

## 2. 生成前先建立风格基准（Style Reference）

基于阶段2 设计系统和已有 IP/Logo 的特征，整理一份简短的风格描述基准，例如："扁平插画风格，圆润线条，2-3级阴影，主色蓝紫渐变，IP角色表情友好亲和"——每次生成新素材时都参照这份基准写 prompt，保证多张素材之间风格统一，而不是每次即兴描述导致风格漂移。

## 3. 调用方式

检查当前运行环境里实际可用的生图能力（取决于具体 IDE/Agent 环境配置的工具或 MCP 服务），优先使用环境已集成的生图模型/技能；如果环境暂未配置生图能力，明确告知用户当前无法自动生图，建议的替代方案（如使用开源图标库补齐、或提示用户自行准备）。不要假设某个特定生图服务一定存在。

## 4. 生成后的质检流程

- 实际打开生成的图片检查：风格是否和风格基准一致、是否和已有 Logo/IP 放在一起显得违和
- 不一致的直接重新生成（调整 prompt），不要将就使用风格冲突的素材
- 统一素材命名和存放规范（如按页面/模块分文件夹），方便开发阶段直接引用

## 5. 版权与合规边界

- 生成的素材必须是原创产出，不能要求生图工具"模仿某个具体品牌/角色"
- 不能直接抓取、使用其他网站的图片/插画作为素材，包括"借鉴构图"演变成的高度相似复刻
- 参考优秀案例时，学习的是布局思路和交互模式，不是具体的图片素材本身
