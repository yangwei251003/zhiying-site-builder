# 阶段6 · 流水线式开发计划书模板

开发计划书要拆到"可以直接认领执行"的粒度，不是"做前端""做后端"这种笼统任务。按里程碑分组，每个里程碑有清晰的验收标准。

```markdown
# 职映网站开发计划书

## 里程碑 0：基础设施搭建
- [ ] 初始化前端项目（技术栈、目录结构、Lint/格式化规则）
- [ ] 初始化后端项目（框架、目录结构、数据库连接）
- [ ] 接入设计系统 token（色彩/字体/间距变量化，全局可用）
- [ ] 搭建基础 CI（代码提交自动检查格式/类型）
验收标准：本地能跑通一个空白页面，前后端能互相调通一个健康检查接口

## 里程碑 1：账号与基础框架
- [ ] 用户注册/登录接口与页面
- [ ] 全站导航、页脚、响应式布局框架
- [ ] 首页 Hero 区 + 功能介绍区实现（接入阶段4生成的素材）
验收标准：用户能注册登录，首页视觉还原设计稿，桌面/移动端均正常展示

## 里程碑 2：知识库构建模块
- [ ] 知识库数据模型与接口（创建/更新/查询）
- [ ] 分步骤引导式前端交互（对照 resumecraft 的模块顺序与追问规则）
- [ ] 完整性自检反馈呈现
验收标准：完整走一遍能建出一份通过自检的知识库，数据正确持久化

## 里程碑 3：岗位匹配模块
- [ ] JD 输入（文本/图片）接口与解析逻辑接入
- [ ] 三分组匹配结果的数据接口与可视化呈现
- [ ] 岗位客观评价展示
验收标准：输入一份真实JD，能得到结构清晰、内容合理的匹配分析结果

## 里程碑 4：简历生成模块
- [ ] 简历内容生成接口（接入 resumecraft 排版脚本）
- [ ] 简历预览与编辑前端
- [ ] 导出下载（docx/pdf）
- [ ] 一页篇幅自动校验与超出提示
验收标准：能生成一份排版正常、确认是一页的简历文件并成功下载

## 里程碑 5：个人中心与历史管理
- [ ] 多知识库/多简历版本管理
- [ ] 历史记录查看

## 里程碑 6（如涉及）：订阅与支付
- [ ] 价格页
- [ ] 支付接入与订阅状态管理

## 里程碑 7：打磨与上线准备
- [ ] 阶段8 自检走查与问题修复
- [ ] 性能优化（首屏加载、图片懒加载等）
- [ ] 阶段9 交付文档产出
- [ ] 生产环境部署与上线检查清单
```

每个里程碑完成后，做一次简短的进度汇报给用户：完成了什么、遇到了什么需要决策的问题、下一个里程碑预计的内容，让用户全程跟得上进度而不是等到最后才看到成品。
