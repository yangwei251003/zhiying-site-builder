# 职映网站开发工作流

围绕求职产品，从需求、设计系统、页面和架构到开发、自检、交付的阶段模板。

![工作流示意，非运行截图](docs/workflow.svg)

## 实际范围

这是开发过程的Skill，不是职映网站本身。完整执行依赖宿主的编码、图像和浏览器能力，以及用户合法提供的素材；不会因安装自动发布网站。

## 安装与调用

1. 准备支持 `SKILL.md` 的AI Agent宿主。
2. 将完整目录以 `zhiying-site-builder` 放入该宿主的用户技能目录；Codex示例为当前用户下的 `.codex/skills/`，其他宿主按其说明配置。
3. 保留正文与子目录相对结构，重新加载技能清单；调用方式取决于宿主。

示例：

> 用 $zhiying-site-builder 根据我提供的求职网站需求，梳理现有素材和必须确认的产品问题，按阶段准备交付文档。

## 技术与文件

Markdown工作流与参考模板由宿主按需读取；提到的外部Skill属于各自维护者，未随本仓库重新分发。真实比赛材料、客户资料、账号配置、私人状态和依赖缓存不在仓库内。
